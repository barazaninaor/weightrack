# 🏋️‍♂️ WeighTrack - Weight Tracking App

A modern, responsive full-stack web application designed to help users track their weight progress, visualize data with glowing charts, and monitor their goals seamlessly.

## ✨ Features

- **Interactive Charts:** Built with Chart.js, featuring responsive lines and custom glowing visual effects.
- **Goal Tracking:** Set and track your target weight with an integrated visual goal line.
- **Authentication & Database:** Secure user authentication and real-time data synchronization using Firebase Firestore.
- **Mobile-Friendly:** Fully responsive UI optimized for both desktop and mobile devices.

## 🛠️ Tech Stack

- **Frontend:** JavaScript (ES6+), HTML5, CSS3, Chart.js
- **Backend / BaaS:** Firebase (Authentication, Firestore)
- **Bundler:** Webpack, Babel
- **Deployment:** GitHub Pages (via GitHub Actions)
